# Week3_Password_Cracking_Project
Hands-on cybersecurity project demonstrating dictionary-based password cracking using John the Ripper and Johnny GUI in Kali Linux as part of NetworkWalks Week 3 training.

## Project Overview
This project focuses on understanding password hashing and dictionary-based password cracking techniques using Kali Linux.

## Tools Used
- Kali Linux
- John the Ripper
- Johnny GUI
- NetworkWalks Password Cracker Lab

## Tasks Performed
1. Extracted the PDF password hash.
2. Prepared the hash for password-cracking analysis.
3. Performed a dictionary attack.
4. Used John the Ripper / Johnny to identify the test password.
5. Verified the password and successfully captured the project flag.

## Learning Outcomes
- Understanding password hashes.
- Learning dictionary attacks.
- Practical experience with John the Ripper.
- Understanding password security and ethical hacking.

## Disclaimer
This project was performed in an authorized educational lab environment for cybersecurity learning purposes.
